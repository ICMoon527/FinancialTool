## 1. 策略速览

| 项目 | 内容 |
|------|------|
| **策略名称** | 天道超跌买入 + 动态分级止盈 V1.0 |
| **策略类型** | 超跌反弹买入 + 阶梯式移动止盈 |
| **选股逻辑** | 出现天道指标**▲买入信号**（td_xg == 1）的股票 |
| **退出逻辑** | 固定止损 + 阶梯式移动止盈 + 时间止损 |
| **买入时机** | 信号日收盘确认 → **当天收盘价买入** |
| **卖出时机** | 触发条件时**当日收盘卖出** |
| **持有上限** | 每次只持有 **1 只**股票 |
| **大盘过滤** | 上证指数站上 20 日均线时才开仓 |
| **适用市场** | 沪市主板（60xxxx）+ 深市主板（00xxxx） |

### 一句话概括

> 等一只股票出现"超跌买入信号"，第二天开盘买入，然后用"阶梯式移动止盈"保护好利润，跌破止损线就认赔出局。

## 2. 核心概念解释

### 2.1 天道指标的四条线

| 名称 | 图中颜色 | 含义 |
|------|----------|------|
| **金钻趋势**（td_jinzuan） | 红色粗线 | 通道下轨，**支撑位**。股价跌到这条线附近说明超跌了 |
| **金牛**（td_jinniu） | 黄色虚线 | 通道上轨，**压力位**。股价涨到这条线附近说明到顶了 |
| **金牛2**（td_jinniu2） | 青色粗线 | 慢速跟随线，是金钻趋势的平滑版，用来判断趋势强弱 |
| **BBI** | 多空线 | 多空分界线，线上偏多，线下偏空 |

### 2.2 ▲买入信号（td_xg）

买入信号需要同时满足两个条件：

**条件①：金钻趋势 > 当日最高价**

意思是：当天**整根 K 线**（包括上影线）都在金钻趋势线下方，说明股价已经跌到支撑位以下，处于超跌状态。

```
金钻趋势 = 10.00 元
当日最高价 = 9.80 元
→ 金钻趋势(10.00) > 最高价(9.80) ✓ 超跌成立
```

**条件②：回调买（动量反转）**

意思是：股价下跌的动能已经衰竭，开始出现反转迹象。这是一个技术指标的综合判断，不需要手动计算，交易软件会自动算好。

**两个条件同时满足 → 出现 ▲买入信号 → 纳入候选**

### 2.3 主力控盘度

衡量一只股票被主力资金控制程度的指标。数值越高，说明主力控盘越强，反弹概率越大。

选股时，按主力控盘度从高到低排序，优先选择控盘度最高的那只。

### 2.4 大盘趋势过滤器

上证指数收盘价必须站上其 20 日均线，才允许开仓买入。指数在 20 日均线下方时，不开新仓，但不影响已持仓的卖出。

## 3. 买入规则

### 3.1 买入流程

```
第1步（信号日 T 日，14:50 之后）：
  ┌─────────────────────────────────────────┐
  │ 接近收盘时（14:50-15:00），查看天道指标   │
  │ 找出所有出现 ▲买入信号（td_xg == 1）的    │
  │ 股票，按主力控盘度排序，选控盘度最高的     │
  │ 那只作为买入目标                          │
  │ 确认后，以当天收盘价直接买入              │
  └─────────────────────────────────────────┘
                      ↓
第2步（买入完成）：
  ┌─────────────────────────────────────────┐
  │ 买入当天不卖（T+1 规则），从明天开始      │
  │ 检查卖出条件                              │
  └─────────────────────────────────────────┘
```

### 3.2 买入条件清单

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 出现 ▲买入信号 | `td_xg == 1`，必须满足 |
| 2 | 非除权跳空 | 当日开盘价相比前日收盘跌幅超过 10.5% 的排除（通常是除权除息） |
| 3 | 当前空仓 | 没有持仓时才买入 |
| 4 | 大盘站上 MA20 | 上证指数收盘价 > 20 日均线（否则不开新仓） |

### 3.3 买入数量计算

```
买入金额 = 账户可用现金 × (1 - 0.5%)    ← 预留 0.5% 交易成本
买入股数 = 买入金额 ÷ (收盘价 × 1.001)   ← 收盘价上浮 0.1% 算滑点
买入股数 = 向下取整到 100 的倍数           ← 以"手"为单位（1手 = 100股）
```

**举例**：
- 账户现金：100,000 元
- 收盘价：9.75 元
- 买入金额 = 100,000 × 0.995 = 99,500 元
- 买入股数 = 99,500 ÷ (9.75 × 1.001) = 99,500 ÷ 9.76 ≈ 10,194
- 取整到 100 的倍数 → **10,100 股**
- 实际成交金额 = 10,100 × 9.76 = 98,576 元
- 剩余现金 = 100,000 - 98,576 = 1,424 元

### 3.4 买入前务必检查

| 检查项 | 怎么检查 |
|--------|----------|
| 大盘位置 | 打开上证指数（000001），看收盘价是否在 20 日均线上方 |
| 信号有效性 | 盘中确认 td_xg == 1，接近收盘时再次确认 |
| 主力控盘度 | 按控盘度排序，选最高的那只 |
| 除权跳空 | 开盘价比前日收盘低超过 10.5% 的放弃 |

## 4. 卖出规则

### 4.1 三条卖出规则（按优先级排列）

> **所有卖出都以收盘价为准**，盘中不判断、不操作。即使盘中跌破止损线，只要收盘价收回止损线以上，就不卖。

#### 规则①：止损出局（最重要）

```
条件：当日收盘价 ≤ 买入价 × 0.93              ← 即亏损达到 7%
动作：以收盘价全部卖出
```

**举例**：
- 买入价：10.00 元
- 止损价：10.00 × 0.93 = 9.30 元
- 今日收盘价：9.10 元（≤ 9.30）→ 触发止损，以 9.10 元卖出

**特殊情况——跌停封死**：
- 如果收盘价已经跌停（≤ 昨收 × 0.9），且成交量极小（不到 20 日均量的 10%），说明卖单排不出去，**无法卖出**，只能继续持有，等明天再判断
- 跌停封死时，不强制卖出，持仓进入第二天

**盘中跌破但尾盘收回 → 不卖**：
- 假设某天盘中一度跌到 9.00 元（低于止损价 9.30），但收盘价收在 9.50 元（高于止损价 9.30）
- 结论：**不触发卖出，继续持有**。只有在收盘时确认跌破止损价才会执行卖出

#### 规则②：阶梯式移动止盈

这是本策略的**核心卖点**，目的是在股价上涨时保护利润。

```
移动止盈价 = 持仓期间最高价 × (1 - 回撤容忍度)
```

**回撤容忍度取决于持仓期间曾达到的最大盈利**：

| 曾达到的最大盈利 | 回撤容忍度 | 含义 |
|------------------|-----------|------|
| < 30% | 10% | 允许从最高点回落 10% 再卖 |
| 30%~50% | 8% | 盈利超过 30% 后，收紧到回落 8% 就卖 |
| ≥ 50% | 5% | 盈利超过 50% 后，非常紧，回落 5% 就卖 |

**关键特性**：
- 移动止盈价**只会往上移，不会往下移**。即使股价回落，止盈价也不会降低，保证利润不丢失
- 基于**曾达到的最高价**计算，而不是当前价。比如股价曾经涨到 15 元（盈利 50%），之后回落到 13 元，止盈价按 15 元 × 95% = 14.25 元计算，而不是按 13 元计算

**举例**：
```
买入价：10.00 元
第 5 天：股价最高涨到 12.50 元（盈利 25%）
  → 回撤容忍 10%，移动止盈价 = 12.50 × 0.90 = 11.25 元
  → 今日收盘价 11.00 元 ≤ 11.25 → 触发移动止盈，以 11.00 元卖出
  → 盈利：(11.00 - 10.00) / 10.00 = 10%

第 10 天：股价最高涨到 14.00 元（盈利 40%）
  → 回撤容忍 8%，移动止盈价 = 14.00 × 0.92 = 12.88 元
  → 今日收盘价 12.50 元 ≤ 12.88 → 触发移动止盈

第 20 天：股价最高涨到 16.00 元（盈利 60%）
  → 回撤容忍 5%，移动止盈价 = 16.00 × 0.95 = 15.20 元
  → 今日收盘价 15.00 元 ≤ 15.20 → 触发移动止盈
```

#### 规则③：时间止损

```
条件：持股超过 30 个交易日，且收益率 ≤ 0%（即不赚钱或亏损）
动作：以收盘价全部卖出
```

**目的**：防止股票既不涨也不跌，一直横盘，占用资金。持有 30 天还没赚钱，说明这票不对，先出来再说。

**举例**：
- 买入价：10.00 元
- 持有天数：第 31 天
- 今日收盘价：10.05 元（收益率 0.5%）
- 0.5% > 0% → 不触发，继续持有

- 买入价：10.00 元
- 持有天数：第 31 天
- 今日收盘价：9.90 元（收益率 -1%）
- -1% ≤ 0% → 触发时间止损，以 9.90 元卖出

### 4.2 三条规则的检查顺序

```
收盘后（15:00），按以下顺序检查：

  第 1 步：检查止损（收盘价 ≤ 止损价？）
    ├─ 是 → 跌停封死？ → 继续持有 → 结束
    └─ 否 → 以收盘价卖出 → 结束

  第 2 步：检查移动止盈（收盘价 ≤ 移动止盈价？）
    ├─ 是 → 跌停封死？ → 继续持有 → 结束
    └─ 否 → 以收盘价卖出 → 结束

  第 3 步：检查时间止损（持股 ≥ 30 天且收益 ≤ 0%？）
    ├─ 是 → 以收盘价卖出
    └─ 否 → 继续持有
```

### 4.3 T+1 规则（重要）

**买入当天无论如何都不卖**。即使当天股价跌停，也等到第二天再处理。

## 5. 每日操作流程

### 5.1 空仓状态（没有持仓时）

#### 每天尾盘（14:50 - 15:00）

```
步骤 ①：检查大盘
  打开上证指数（000001），看收盘价是否在 20 日均线上方
  不在 → 不操作，等明天
  在 → 继续下一步

步骤 ②：运行选股
  在全市场按天道指标筛选，找出出现 ▲买入信号（td_xg == 1）的股票

步骤 ③：排序
  按主力控盘度从高到低排序，选出控盘度最高的那只

步骤 ④：检查除权跳空
  如果当日开盘价 < 前日收盘 × 0.895（跌幅超过 10.5%），放弃

步骤 ⑤：以收盘价买入
  确认目标后，立即以当天收盘价买入（按第 3.3 节的公式计算股数）
```

> 注意：买入和卖出都是**同一天收盘时**操作。如果刚好有持仓需卖出，先处理卖出，再买入新股。

### 5.2 持仓状态（持有股票时）

#### 每天（从买入第二天开始）

| 时间 | 做什么 |
|------|--------|
| **9:30 - 15:00** | 不用操作，等收盘 |
| **15:00** | 收盘后，检查是否触发卖出条件（见第 4 节） |
| **如果触发** | 以收盘价卖出 |
| **如果未触发** | 继续持有，明天再看 |

```
                    ┌──────────────┐
                    │  今日是什么状态？ │

            ┌──────────────┴──────────────┐

      │  空仓    │                  │  持仓    │

           │                             │
     收盘后检查：                 收盘后检查：
     ① 大盘 > MA20？              ① 止损？→ 卖出

     ③ 有 → 收盘价买入            ③ 时间止损？→ 卖出

## 6. 交易成本

| 费用项 | 费率 | 什么时候收 |
|--------|------|-----------|
| **手续费** | 成交金额的 **0.1%** | 买入和卖出各收一次 |
| **滑点** | 买入价上浮 **0.1%** | 只在买入时收（模拟买入时无法精确以开盘价成交的损失） |
| **预留成本** | 买入时预留 **0.5%** | 含手续费 0.1% + 滑点 0.1% + 安全边际 0.3% |

**举例**（买入 10,000 元）：
- 手续费：10,000 × 0.1% = 10 元
- 滑点：10,000 × 0.1% = 10 元
- 卖出时再收一次手续费：假设卖出 11,000 元，手续费 11 元
- 总交易成本约 31 元，占比约 0.3%

## 8. 完整交易示例

### 8.1 第 1 天：发现信号 + 买入（T 日）

```
日期：2026-03-10（周二）
大盘：上证指数收盘 3,250 点，20 日均线 3,200 点 → 站上均线 ✓

尾盘 14:50，运行选股：
  股票代码：600123
  股票名称：兰花科创
  买入信号：td_xg == 1 ✓  （金钻趋势 > 最高价，且回调买成立）
  主力控盘度：78.5（全场最高）
  除权检测：开盘价 12.45，前日收盘 12.50，跌幅 0.4% → 正常 ✓

决策：以收盘价 12.50 元买入

买入金额 = 100,000 × 0.995 = 99,500 元
买入股数 = 99,500 ÷ (12.50 × 1.001) = 99,500 ÷ 12.5125 ≈ 7,952
          → 取整到 100 的倍数 → 7,900 股
实际成交金额 = 7,900 × 12.5125 = 98,848.75 元
剩余现金 = 100,000 - 98,848.75 = 1,151.25 元

重要：买入当天不卖（T+1 规则）

### 8.2 第 2~15 天：持有期

```
第 2 天（3/11）：收盘 12.80 元，盈利 2.4%
  → 未触发任何卖出条件，继续持有

第 5 天（3/14）：收盘 13.50 元，盈利 8%
  → 移动止盈价 = 13.50 × 0.90 = 12.15 元 ← 盈利 < 30%，回撤 10%
  → 收盘 13.50 > 12.15，不触发

第 10 天（3/23）：收盘 14.20 元，盈利 13.6%
  → 移动止盈价 = 14.20 × 0.90 = 12.78 元
  → 收盘 14.20 > 12.78，不触发

第 12 天（3/25）：盘中最高 15.80 元，盈利 26.4%
  → 移动止盈价 = 15.80 × 0.90 = 14.22 元
  → 收盘 15.20 > 14.22，不触发

第 15 天（3/30）：盘中最高 16.50 元，盈利 32%
  → 盈利超过 30%，回撤容忍收紧到 8%
  → 移动止盈价 = 16.50 × 0.92 = 15.18 元
  → 收盘 15.50 > 15.18，不触发
```

### 8.3 第 18 天：触发移动止盈

```
第 18 天（4/4）：盘中最高 17.00 元，盈利 36%
  → 移动止盈价 = 17.00 × 0.92 = 15.64 元
  → 收盘 15.30 元 ≤ 15.64 → 触发移动止盈！

卖出：以收盘价 15.30 元全部卖出
成交金额 = 7,900 × 15.30 = 120,870 元
手续费 = 120,870 × 0.1% = 120.87 元
实际到账 = 120,870 - 120.87 = 120,749.13 元

总现金 = 1,151.25 + 120,749.13 = 121,900.38 元

收益率 = (121,900.38 - 100,000) / 100,000 = 21.9%
```

### 8.4 比较：止损出局的情况

```
如果走势相反：

买入价：12.50 元
止损价：12.50 × 0.93 = 11.625 元

第 5 天（3/14）：收盘 10.80 元
  → 10.80 ≤ 11.625 → 触发止损
  → 检查是否跌停封死：跌停价 = 昨收 × 0.9
  → 如果未封死，以 10.80 元卖出
  → 亏损：(10.80 - 12.50) / 12.50 = -13.6%
```

### 8.5 比较：时间止损的情况

```
买入价：12.50 元

第 31 天（4/21）：收盘 12.45 元
  → 持股 31 天 ≥ 30 天
  → 收益率 = (12.45 - 12.50) / 12.50 = -0.4%
  → -0.4% ≤ 0% → 触发时间止损
  → 以 12.45 元卖出
  → 亏损：(12.45 - 12.50) / 12.50 = -0.4%（含手续费实际微亏）
```

## 9. 常见问题

### Q1：我需要在盘中盯着看吗？

**不需要。** 尾盘检查一次就行。买入在尾盘（14:50-15:00）确认信号后以收盘价买入；卖出在收盘后检查条件，以收盘价执行。

### Q2：▲买入信号每天都会出现吗？

**不一定。** 有时一天会出现好几只，有时连续几天一只都没有。没有信号的时候就空仓等待，不要强行交易。

### Q3：如果尾盘买入后，第二天开盘大跌怎么办？

**按规则执行。** 买入当天（T+1 规则）不卖，从第二天开始检查止损条件。如果第二天收盘跌破止损价（买入价 × 0.93），就按规则卖出。策略设计上已经考虑了跳空风险，止损线就是用来应对这种情况的。

### Q4：跌停封死卖不出怎么办？

**继续持有，等明天。** 跌停封死时，卖单排不出去，系统会自动判断为"无法卖出"，持仓进入第二天。第二天继续按正常规则检查。

### Q5：如果买了之后连续大涨，什么时候卖？

**等移动止盈触发。** 股价涨得越高，移动止盈价也越高，利润保护得越好。不需要自己判断"是不是该卖了"，让规则帮你做决定。

### Q6：如果同时有多只股票出现买入信号，买哪只？

**按主力控盘度排序，选最高的那只。** 如果控盘度相同，按策略得分排序。

### Q7：大盘在 20 日均线下方时，可以买入吗？

**不可以。** 大盘在 20 日均线下方说明市场整体偏弱，不开新仓。但已持仓的股票不受影响，正常按卖出规则执行。

### Q8：盘中跌破止损线，但收盘又涨回来了，卖不卖？

**不卖。** 所有卖出都以收盘价为准。盘中跌破止损线只是"虚晃一枪"，只要收盘价回到止损线以上，就继续持有。这是为了防止被盘中波动震出。

## 10. 风险提示

1. **历史回测不代表未来收益**。过去表现好的策略，未来可能表现不佳。

2. **策略有连续止损的可能**。特别是在熊市中，可能出现连续买入、连续止损的情况。建议设置总资金回撤上限（如 20%），达到后暂停交易。

3. **跌停板无法应对极端行情**。连续跌停时，策略无法及时止损，可能导致超出预期的亏损。

4. **本策略基于日线级别**，对盘中突发消息（如突发利空、停牌等）无法及时反应。

5. **建议使用前复权数据**，避免除权除息导致信号失真。

6. **实盘 vs 回测的差异**：

| 方面 | 回测 | 实盘建议 |
|------|------|----------|
| 成交价 | 按指定价格精确成交 | 使用限价单，避免滑点过大 |
| 跌停板 | 假设可以卖出 | 跌停板可能无法卖出，需人工判断 |
| 流动性 | 忽略 | 选择日成交额 > 5000 万的股票 |
| 信号延迟 | 无 | 预留数据获取时间 |
