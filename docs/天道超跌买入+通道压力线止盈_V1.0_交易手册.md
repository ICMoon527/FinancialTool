## 1. 策略速览

| 项目 | 内容 |
|------|------|
| **策略名称** | 天道超跌买入 + 通道压力线分批止盈 V1.0 |
| **策略类型** | 超跌反弹买入 + 通道压力线分批止盈 |
| **选股逻辑** | 出现天道指标**▲买入信号**（td_xg == 1）的股票 |
| **退出逻辑** | 固定止损 + 通道压力线分批止盈（A/B/C 档）+ 时间止损 |
| **买入时机** | 信号日收盘确认 → **当天收盘价买入** |
| **卖出时机** | 触发条件时**当日收盘卖出** |
| **持有上限** | 每次只持有 **1 只**股票 |
| **大盘过滤** | 上证指数站上 20 日均线时才开仓 |
| **适用市场** | 沪市主板（60xxxx）+ 深市主板（00xxxx） |

### 一句话概括

> 等一只股票出现"超跌买入信号"，当天收盘买入。然后用"金牛线压力位"分批止盈：涨到压力位先卖 1/3，回落再卖 1/3，全程用移动止盈保护剩余仓位，跌破止损线就认赔出局。

## 2. 核心概念解释

### 2.1 天道指标的四条线

| 名称 | 图中颜色 | 含义 |
|------|----------|------|
| **金钻趋势**（td_jinzuan） | 红色粗线 | 通道下轨，**支撑位**。股价跌到这条线附近说明超跌了 |
| **金牛**（td_jinniu） | 黄色虚线 | 通道上轨，**压力位**。股价涨到这条线附近说明到顶了 |
| **金牛2**（td_jinniu2） | 青色粗线 | 慢速跟随线，是金钻趋势的平滑版，用来判断趋势强弱 |
| **BBI** | 多空线 | 多空分界线，线上偏多，线下偏空 |

### 2.2 压力位（pressure）

```
压力位 = 昨日金牛线值（REF(金牛, 1)）
```

意思是：**用昨天那条金牛线（通道上轨压力位）的位置，作为今天的参考压力价**。

为什么用昨天的？因为金牛线是靠收盘价平滑算出来的慢速线，今天还没走完、一天内会浮动。取"昨天的金牛值"作为今天固定的压力位，更稳定、可操作，方便你提前挂单判断。

**举例**：
- 昨日金牛线值 = 15.00 元
- 则今日压力位 = **15.00 元**
- 今天股价最高最高涨到 15.20 元，碰触到了压力位 → 触发 A 档

> 另有一个"支撑位" = 昨日金钻线值，只作为备用监控参考，**不参与任何卖出判断**。

### 2.3 分批止盈的三档（A/B/C 档）

这是本策略的**核心卖点**。持仓后，按"碰压力位→回落→移动止盈"三步走，逐步落袋：

| 档位 | 触发时机 | 卖出比例 |
|------|----------|----------|
| **A 档** | 首次触碰到压力位 | 卖出 **1/3** |
| **B 档** | A 档之后，从压力位回落 | 卖出剩余的一半（即原仓的 **1/3**） |
| **C 档** | 全程移动止盈保护 | 卖出**全部剩余仓位** |

> 注意：C 档优先级最高，任何时刻只要移动止盈被触发了，就全部卖出，不管 A/B 档到没到。

### 2.4 主力控盘度 & 大盘趋势过滤器

- **主力控盘度**：衡量主力资金控盘程度，数值越高反弹概率越大。选股时按控盘度从高到低排序，选最高的那只。
- **大盘趋势过滤器**：上证指数收盘价必须站上其 20 日均线才允许开仓；指数在 20 日均线下方时不开新仓，但不影响已持仓的卖出。

## 3. 买入规则

### 3.1 买入流程

```
第1步（信号日 T 日，14:50 之后）：
  ┌─────────────────────────────────────────┐
  │ 接近收盘时（14:50-15:00），查看天道指标   │
  │ 找出所有出现 ▲买入信号（td_xg == 1）的    │
  │ 股票，按主力控盘度排序，选控盘度最高的     │
  │ 那只作为买入目标                          │
  │ 确认后，以当天收盘价直接买入              │
  └─────────────────────────────────────────┘
                      ↓
第2步（买入完成）：
  ┌─────────────────────────────────────────┐
  │ 买入当天不卖（T+1 规则），从明天开始      │
  │ 检查卖出条件                              │
  └─────────────────────────────────────────┘
```

### 3.2 买入条件清单

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 出现 ▲买入信号 | `td_xg == 1`，必须满足 |
| 2 | 非除权跳空 | 当日开盘价相比前日收盘跌幅超过 10.5% 的排除（通常是除权除息） |
| 3 | 当前空仓 | 没有持仓时才买入 |
| 4 | 大盘站上 MA20 | 上证指数收盘价 > 20 日均线（否则不开新仓） |

### 3.3 买入数量计算

```
买入金额 = 账户可用现金 × (1 - 0.5%)    ← 预留 0.5% 交易成本
买入股数 = 买入金额 ÷ (收盘价 × 1.001)   ← 收盘价上浮 0.1% 算滑点
买入股数 = 向下取整到 100 的倍数           ← 以"手"为单位（1手 = 100股）
```

**举例**：
- 账户现金：100,000 元
- 收盘价：9.75 元
- 买入金额 = 100,000 × 0.995 = 99,500 元
- 买入股数 = 99,500 ÷ (9.75 × 1.001) = 99,500 ÷ 9.76 ≈ 10,194
- 取整到 100 的倍数 → **10,100 股**
- 实际成交金额 = 10,100 × 9.76 = 98,576 元
- 剩余现金 = 100,000 - 98,576 = 1,424 元

### 3.4 买入前务必检查

| 检查项 | 怎么检查 |
|--------|----------|
| 大盘位置 | 打开上证指数（000001），看收盘价是否在 20 日均线上方 |
| 信号有效性 | 盘中确认 td_xg == 1，接近收盘时再次确认 |
| 主力控盘度 | 按控盘度排序，选最高的那只 |
| 除权跳空 | 开盘价比前日收盘低超过 10.5% 的放弃 |

## 4. 卖出规则

> **所有卖出都以收盘价为准**，盘中不判断、不操作。即使盘中跌破止损线，只要收盘价收回止损线以上，就不卖。

### 4.1 卖出优先级总览

```
收盘后（15:00），按以下优先级逐项检查，先触发哪个就先执行哪个、且只执行一个：

  ① C 档：全程移动止盈（优先级最高）
  ② A 档：首次触碰到压力位 → 卖出 1/3
  ③ B 档：A 档后从压力位回落 → 卖出剩余 1/2（即原仓 1/3）
  ④ 止损（7%）
  ⑤ 时间止损（30 天）
```

### 4.2 C 档：全程移动止盈（优先级最高）

> 从买入第一天起，**全程跟踪保护剩余仓位**。它的作用是不管股价涨到哪，只要从最高点掉头下跌超过容忍度，就全部落袋。

```
移动止盈价 = 持仓期间最高价 × (1 - 回撤容忍度)
```

**回撤容忍度取决于持仓期间曾达到的最大盈利**：

| 曾达到的最大盈利 | 回撤容忍度 | 含义 |
|------------------|-----------|------|
| < 30% | 10% | 允许从最高点回落 10% 再卖 |
| 30%~50% | 8% | 盈利超过 30% 后，收紧到回落 8% 就卖 |
| ≥ 50% | 5% | 盈利超过 50% 后，非常紧，回落 5% 就卖 |

**关键特性**：
- 移动止盈价**只会往上移，不会往下移**。即使股价回落，止盈价也不会降低，保证利润不丢失。
- 基于**曾达到的最高价**（含盘中最高价）计算，而不是当前价。
- 只要**收盘价 ≤ 移动止盈价**，就把剩余仓位**全部卖出**。
- **C 档优先级最高**：它一旦触发，就立即全部清仓，A/B 档还没触发也不再继续等。

**举例**：
```
买入价：10.00 元
第 5 天：股价最高涨到 12.50 元（盈利 25%）
  → 移动止盈价 = 12.50 × 0.90 = 11.25 元
  → 今日收盘价 11.00 元 ≤ 11.25 → 触发 C 档，全部卖出
  → 盈利：(11.00 - 10.00) / 10.00 = 10%
```

### 4.3 A 档：首次触碰到压力位

```
条件：持仓期间从未触发过 A 档，且当日最高价 ≥ 压力位
动作：以压力位价格卖出 1/3 仓位
```

**举例**：
- 买入价：10.00 元，共买入 3,000 股
- 压力位 = 昨日金牛值 = 15.00 元
- 今日盘中最高涨到 15.20 元（≥ 15.00）→ 触发 A 档
- 以 **15.00 元** 卖出 1/3 = **1,000 股**
- 剩余 2,000 股继续持有

> A 档用"最高价"触碰判断，但**卖出的成交价是压力位本身**（15.00 元），假设你挂在压力位排队成交。

### 4.4 B 档：A 档后从压力位回落

```
条件：A 档已完成，且当日收盘价 < 压力位
动作：尾盘卖出剩余仓位的一半（即原仓的 1/3）
```

**举例**（接上面）：
- A 档卖出 1,000 股后，剩余 2,000 股
- 第二天收盘价 14.80 元（< 压力位 15.00）→ 触发 B 档
- 以 **14.80 元** 卖出剩余一半 = **1,000 股**
- 还剩 1,000 股继续持有

> 到这里，原仓 3,000 股已分批走掉了 2,000 股（1/3 + 1/3），只剩最后 1/3 交给 C 档和止损、时间止损继续管理。

### 4.5 止损出局（7%）

```
条件：当日收盘价 ≤ 买入价 × 0.93   ← 即亏损达到 7%
动作：以收盘价全部卖出
```

**特殊情况——跌停封死**：
- 如果收盘价已经跌停（≤ 昨收 × 0.9），且成交量极小（不到 20 日均量的 10%），说明卖单排不出去，**无法卖出**，只能继续持有，等明天再判断。
- 跌停封死时，不强制卖出，持仓进入第二天。

**盘中跌破但尾盘收回 → 不卖**：
- 假设某天盘中一度跌到 9.00 元（低于止损价 9.30），但收盘价收在 9.50 元（高于止损价 9.30）
- 结论：**不触发卖出，继续持有**。只有收盘时确认跌破止损价才会执行。

### 4.6 时间止损

```
条件：持股超过 30 个交易日，且收益率 ≤ 0%（即不赚钱或亏损）
动作：以收盘价全部卖出
```

**目的**：防止股票既不涨也不跌，一直横盘占用资金。持有 30 天还没赚钱，说明这票不对，先出来再说。

**举例**：
- 买入价：10.00 元
- 持有天数：第 31 天
- 今日收盘价：9.90 元（收益率 -1%）
- -1% ≤ 0% → 触发时间止损，以 9.90 元卖出

### 4.7 检查顺序（一图记住）

```
收盘后（15:00），按以下顺序依次检查，命中即停：

  ① C 档：收盘价 ≤ 移动止盈价？
      ├─ 是 → 跌停封死？→ 继续持有 → 结束
      └─ 否 → 全部卖出 → 结束

  ② A 档：最高价 ≥ 压力位 && 未卖过 1/3？
      ├─ 是 → 跌停封死？→ 继续持有 → 结束
      └─ 否 → 以压力位卖出 1/3 → 结束

  ③ B 档：A 档已完成 && 收盘价 < 压力位？
      ├─ 是 → 跌停封死？→ 继续持有 → 结束
      └─ 否 → 以收盘价卖出剩余 1/2 → 结束

  ④ 止损：收盘价 ≤ 买入价 × 0.93？
      ├─ 是 → 跌停封死？→ 继续持有 → 结束
      └─ 否 → 以收盘价全部卖出 → 结束

  ⑤ 时间止损：持股 ≥ 30 天 && 收益率 ≤ 0%？
      ├─ 是 → 以收盘价全部卖出
      └─ 否 → 继续持有
```

### 4.8 T+1 规则（重要）

**买入当天无论如何都不卖**。即使当天股价跌停，也等到第二天再处理。

## 5. 每日操作流程

### 5.1 空仓状态（没有持仓时）

#### 每天尾盘（14:50 - 15:00）

```
步骤 ①：检查大盘
  打开上证指数（000001），看收盘价是否在 20 日均线上方
  不在 → 不操作，等明天
  在 → 继续下一步

步骤 ②：运行选股
  在全市场按天道指标筛选，找出出现 ▲买入信号（td_xg == 1）的股票

步骤 ③：排序
  按主力控盘度从高到低排序，选出控盘度最高的那只

步骤 ④：检查除权跳空
  如果当日开盘价 < 前日收盘 × 0.895（跌幅超过 10.5%），放弃

步骤 ⑤：以收盘价买入
  确认目标后，立即以当天收盘价买入（按第 3.3 节的公式计算股数）
```

> 注意：买入和卖出都是**同一天收盘时**操作。如果刚好有持仓需卖出，先处理卖出，再买入新股。

### 5.2 持仓状态（持有股票时）

#### 每天（从买入第二天开始）

| 时间 | 做什么 |
|------|--------|
| **9:30 - 15:00** | 不用操作，等收盘 |
| **15:00** | 收盘后，按第 4.7 节顺序检查：C 档 → A 档 → B 档 → 止损 → 时间止损 |
| **如果触发** | 按对应档位规则卖出（以收盘价 / 或压力位） |
| **如果未触发** | 继续持有，明天再看 |

```
                    ┌──────────────┐
                    │  今日是什么状态？ │

                           │
            ┌──────────────┴──────────────┐

      └────┬─────┘                  └────┬─────┘
           │                             │
     收盘后检查：                 收盘后检查（按优先级）：
     ① 大盘 > MA20？              ① C档移动止盈？→ 全卖
```

## 6. 交易成本

| 费用项 | 费率 | 什么时候收 |
|--------|------|-----------|
| **手续费** | 成交金额的 **0.1%** | 买入和卖出各收一次 |
| **滑点** | 买入价上浮 **0.1%** | 只在买入时收（模拟买入时无法精确以开盘价成交的损失） |
| **预留成本** | 买入时预留 **0.5%** | 含手续费 0.1% + 滑点 0.1% + 安全边际 0.3% |

**举例**（买入 10,000 元）：
- 手续费：10,000 × 0.1% = 10 元
- 滑点：10,000 × 0.1% = 10 元
- 卖出时再收一次手续费：假设卖出 11,000 元，手续费 11 元
- 总交易成本约 31 元，占比约 0.3%

## 8. 完整交易示例

### 8.1 第 1 天：发现信号 + 买入（T 日）

```
日期：2026-03-10（周二）
大盘：上证指数收盘 3,250 点，20 日均线 3,200 点 → 站上均线 ✓

尾盘 14:50，运行选股：
  股票代码：600123
  股票名称：兰花科创
  买入信号：td_xg == 1 ✓
  主力控盘度：78.5（全场最高）
  除权检测：开盘价 12.45，前日收盘 12.50，跌幅 0.4% → 正常 ✓

决策：以收盘价 12.50 元买入 7,900 股

买入金额 = 100,000 × 0.995 = 99,500 元
买入股数 = 99,500 ÷ (12.50 × 1.001) ≈ 7,952 → 取整 7,900 股
实际成交金额 = 7,900 × 12.5125 = 98,848.75 元
剩余现金 = 100,000 - 98,848.75 = 1,151.25 元

压力位 = 昨日金牛值 = 14.00 元（记住这个值，用来判断 A/B 档）

重要：买入当天不卖（T+1 规则）
```

### 8.2 第 2~12 天：持有期（涨向压力位）

```
第 2 天（3/11）：收盘 12.80 元，盈利 2.4%
  → 未触发任何卖出条件，继续持有

第 5 天（3/14）：收盘 13.50 元，盈利 8%
  → C 档：移动止盈价 = 13.50 × 0.90 = 12.15 元（盈利 < 30%，回撤 10%）
  → 收盘 13.50 > 12.15，C 档不触发

第 8 天（3/19）：盘中最高 13.90 元（< 压力位 14.00）
  → A 档未触发（还没碰到 14.00）

第 12 天（3/25）：盘中最高 14.30 元（≥ 压力位 14.00）→ A 档触发！
  → 以压力位 14.00 元卖出 1/3 = 7,900 × 1/3 ≈ 2,633 股（取整 2,600 股）
  → 剩余约 5,300 股
  → 到账资金 = 2,600 × 14.00 = 36,400 元
```

### 8.3 第 13~16 天：A 档后继续观察（回落触发 B 档？）

```
第 13 天（3/26）：收盘 14.10 元（仍 ≥ 压力位），C 档不触发，B 档也不触发
第 14 天（3/27）：盘中最高 14.60 元，盈利 16.8%
  → C 档：移动止盈价 = 14.60 × 0.90 = 13.14 元
  → 收盘 14.20 > 13.14，不触发
第 16 天（3/30）：收盘 13.00 元（< 压力位 14.00）且 A 档已完成
  → B 档触发！以收盘价 13.00 元卖出剩余 1/2 = 5,300 ÷ 2 ≈ 2,650 股
  → 剩余约 2,650 股
  → 到账资金 = 2,650 × 13.00 = 34,450 元
```

> 到这里，原仓 7,900 股已卖出约 2,600 + 2,650 = 5,250 股，还剩 2,650 股。剩余这部分的卖出完全交给 C 档 / 止损 / 时间止损。

### 8.4 第 20 天：触发 C 档移动止盈（清仓剩余）

```
第 20 天（4/4）：盘中最高 15.50 元（盈利 24%）
  → C 档：移动止盈价 = 15.50 × 0.90 = 13.95 元
  → 今日收盘 13.80 元 ≤ 13.95 → 触发 C 档！
  → 以收盘价 13.80 元全部卖出剩余 2,650 股
  → 到账资金 = 2,650 × 13.80 = 36,570 元（扣手续费后约 36,533 元）
```

**整笔交易回看：**
| 阶段 | 卖出价 | 股数 | 金额 |
|------|--------|------|------|
| A 档 | 14.00 | 2,600 | 36,400 |
| B 档 | 13.00 | 2,650 | 34,450 |
| C 档 | 13.80 | 2,650 | 36,570 |
| **合计** | — | **7,900** | **约 107,420** |

扣掉手续费与最初剩余现金后，账户总体约 +6~7%，实现分批止盈落袋。

## 9. 常见问题

### Q1：A 档我已经卖过 1/3 了，股价又涨回压力位，还会再卖吗？

**不会。** A 档每笔持仓只触发一次（`tier1_done` 标志）。卖过 1/3 之后，即使股价再次触碰压力位，也不会重复卖。后续由 B 档（回落）和 C 档（移动止盈）继续管理。

### Q2：B 档一定要等 A 档之后才可能触发吗？

**是的。** B 档的前提是"A 档已完成、卖过 1/3"。如果股价从下方直接一路冲高从未回落，或者 A 档一直没触发，B 档就不会触发。

### Q3：C 档和 A/B 档同时满足怎么办？

**C 档优先。** C 档是全程最高优先级。一旦收盘价跌破了移动止盈价，就直接全部清仓，不再等 A/B 档。

### Q4：压力位是多少？我盘中能直接看到吗？

**压力位 = 昨日金牛线值**。可以提前一天记下昨天金牛线的数值，作为今天的参考压力价。盘中看最高价是否达到这个值即可判断 A 档是否触发。

### Q5：我需要盘中盯着看吗？

**不需要。** A 档用"当日最高价触达压力位"判断，可以等收盘后用当日最高价核对；B 档用收盘价判断；C 档、止损、时间止损都只用收盘价。收盘后检查一次即可。

### Q6：如果买了之后连续大涨，怎么止盈？

**靠 C 档移动止盈。** 股价涨得越高，移动止盈价跟着越高。同时 A 档会在首触压力位时先锁定 1/3 利润。不需要自己判断"该不该卖"，规则自动分批落袋。

### Q7：A 档按压力位成交，但盘中最高只摸了一下压力位就回落了，能成交吗？

**按回测假设能成交。** 回测假设你在压力位挂了限价单、盘中最高触及即成交。实盘中是否真能成交取决于当时的挂单排队和流动性，建议分批挂单。

### Q8：如果同时有多只股票出现买入信号，买哪只？

**按主力控盘度排序，选最高的那只。** 控盘度相同则按策略得分排序。

### Q9：大盘在 20 日均线下方时可以买入吗？

**不可以。** 大盘在 20 日均线下方不开新仓，但已持仓正常按卖出规则执行。

### Q10：盘中跌破止损线但收盘又涨回来，卖不卖？

**不卖。** 所有卖出以收盘价为准。盘中跌破只是"虚晃一枪"，收盘回到止损线以上就继续持有。

## 10. 风险提示

1. **历史回测不代表未来收益**。过去表现好的策略，未来可能表现不佳。

2. **策略有连续止损的可能**。特别是在熊市中，可能出现连续买入、连续止损的情况。建议设置总资金回撤上限（如 20%），达到后暂停交易。

3. **跌停板无法应对极端行情**。连续跌停时，策略无法及时止损，可能导致超出预期的亏损。

4. **分批止盈不等于规避全部回撤**。A 档若在较高位才触发、随后股价大涨，B 档回落价会相对偏低；且 C 档对剩余仓位仍有最高 5%~10% 的回撤容忍度。

5. **本策略基于日线级别**，对盘中突发消息（如突发利空、停牌等）无法及时反应。

6. **建议使用前复权数据**，避免除权除息导致信号失真。

7. **实盘 vs 回测的差异**：

| 方面 | 回测 | 实盘建议 |
|------|------|----------|
| 成交价 | 按指定价格精确成交 | 使用限价单，避免滑点过大 |
| A 档压力位成交 | 假设触及即成交 | 挂单量可能不足，需人工分批挂单 |
| 跌停板 | 假设可以卖出 | 跌停板可能无法卖出，需人工判断 |
| 流动性 | 忽略 | 选择日成交额 > 5000 万的股票 |
| 信号延迟 | 无 | 预留数据获取时间 |
