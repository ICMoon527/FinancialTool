## 1. 策略概述

| 项目 | 内容 |
|------|------|
| 策略类型 | 趋势回调买入 + 动态分级保护 |
| 选股策略 | 天道超跌反弹（td_xg 信号） |
| 退出策略 | 天道金牛2分级保护 |
| 交易频率 | 低频（仅 td_xg 信号触发时买入） |
| 适用市场 | 沪A主板（60xxxx）+ 深A主板（00xxxx） |
| 最长持股 | 35 个交易日 |
| 最高持仓 | 1 只（默认） |

**核心思想**：等待上升趋势中的股票出现超跌信号（td_xg），在支撑位买入，利用金牛2线对仓位进行动态分级管理，最终在金牛线（压力位）止盈。

## 2. 使用的指标及公式

### 2.1 天道趋势线（4条）

| 指标 | 公式 | 含义 |
|------|------|------|
| **金钻趋势** | `2 × XMA(XMA(L, 25), 25) - XMA(XMA(H, 25), 25)` | 通道下轨（支撑位） |
| **金牛** | `2 × XMA(XMA(H, 25), 25) - XMA(XMA(L, 25), 25)` | 通道上轨（压力位） |
| **金牛2** | `EMA(金钻趋势, 25)` | 慢速跟随线（动态保护线） |
| **BBI** | `(MA(C,3) + MA(C,6) + MA(C,12) + MA(C,24)) / 4` | 多空分界线 |

> XMA 为通达信居中对称移动平均（Centered Moving Average），窗口中心位于当前 K 线。

### 2.2 买入信号：td_xg（▲买入）

```
td_xg = (金钻趋势 > HIGH) AND (回调买)
```

**条件1：金钻趋势 > HIGH**
- 当天最高价仍低于金钻趋势线
- 即整根 K 线完全在支撑位下方
- 确认超跌到支撑区域

**条件2：回调买（VAR23 动量反转）**
```
VAR23 = 100 × XMA(XMA(C - REF(C,1), 6), 6) / XMA(XMA(ABS(C - REF(C,1)), 6), 6)
回调买 = LLV(VAR23, 2) == LLV(VAR23, 7)
        AND COUNT(VAR23 < 0, 2) >= 1
        AND CROSS(VAR23, MA(VAR23, 2))
```

即 VAR23 处于 7 日最低点，最近 2 日中有 VAR23 < 0 的情况，且 VAR23 上穿其 2 日均线（动量金叉）。

## 3. 买入规则

### 3.1 买入时机

```
信号日（Day T）收盘后 → 确认 td_xg == 1 → 次日（Day T+1）开盘买入
```

**关键点**：信号生成需要当日完整 K 线数据（收盘价、最高价、最低价），因此必须在收盘后才能确认信号，次日开盘执行买入。

### 3.2 买入条件

| 条件 | 说明 |
|------|------|
| td_xg == 1 | 必须满足（核心条件） |
| 非除权跳空 | 开盘价相对前日收盘跌幅 > 10.5% 时排除 |
| 未满仓 | 当前持仓数 < 最高持仓数（默认 1） |

### 3.3 买入数量

```
每只股票分配资金 = 可用现金 × (1 - 0.5%) / 待买股票数
买入股数 = floor(分配资金 / (开盘价 × 1.001) / 100) × 100
```

- 预留 0.5% 交易成本（手续费 0.1% + 滑点 0.1% + 安全边际）
- 以 100 股（1 手）为最小单位取整

### 3.4 除权跳空处理

如果信号日开盘价相对前日收盘价跌幅 > 10.5%（超出正常跌停板范围），则判定为除权除息事件。此时自动从数据源获取前复权数据重新评估，确保指标计算不受除权影响。

## 4. 卖出规则

### 4.1 金牛2分级保护体系

```
                金牛 ─────────────────── 止盈清仓（最高价触及即清仓）
                 ↑
                 │   反弹空间
                 │
       买入 →    │
                 │
                金牛2 ─────────────────── 趋势分界线
                 │    ↓ 最低价跌破金牛2 → 趋势转弱
                 │      减仓 50%，剩余 50% 继续持有
                 │
                 │    ↓ 收盘站回金牛2（已减仓状态）→ 趋势恢复
                 │      加仓买回 50%
                 │
                 │    ↓ 最低价跌破金牛2 × 0.95（已减仓状态）→ 趋势走坏
                 │      剩余仓位清仓止损
```

### 4.2 盘中检查（intraday）

按优先级依次检查，触发即执行，不再检查后续条件：

| 优先级 | 当前状态 | 条件 | 动作 | 成交价 |
|--------|----------|------|------|--------|
| 1 | 任意 | 最高价 ≥ 金牛 | **清仓止盈** | 金牛价 |
| 2 | 全仓持有 | 最低价 ≤ 金牛2 | **减仓 50%** | 金牛2价 |
| 3 | 已减仓 | 最低价 ≤ 金牛2 × 0.95 | **清仓止损** | 金牛2 × 0.95 价 |

### 4.3 收盘检查（close）

| 条件 | 动作 | 成交价 |
|------|------|--------|
| 已减仓 且 收盘价 > 金牛2 | **加仓买回 50%** | 收盘价 |
| 持股天数 ≥ 35 | **到期清仓** | 收盘价 |

### 4.4 T+1 规则

买入当天（Day T+1）不检查任何卖出信号，从次日（Day T+2）开始检查。

### 4.5 金牛2保护的特点

- **动态止损**：金牛2 每天随行情变化，止损价跟随移动
- **趋势跟踪**：如果股票上涨，金牛2 缓慢上移，止损价自动抬高，保护更多利润
- **分级管理**：趋势转弱先减仓，趋势走坏再清仓，避免过早被震出

## 5. 持仓管理

### 5.1 最高持仓限制

默认最高持仓 1 只股票。当持仓满时，不会买入新股，即使有新的 td_xg 信号。

### 5.2 加仓机制

减仓后，如果收盘价重新站上金牛2，会加仓买回。加仓使用当前可用现金，买回数量按当前收盘价计算。

### 5.3 状态机

```
         ┌──────────┐
         │  全仓持有  │
         └────┬─────┘
              │ 最低价 ≤ 金牛2（盘中）
              ▼
         ┌──────────┐
         │  半仓持有  │ ← 收盘 > 金牛2（加仓买回）
         └────┬─────┘
              │ 最低价 ≤ 金牛2 × 0.95（盘中）
              │ 或 持股 ≥ 35 天（收盘）
              ▼
         ┌──────────┐
         │   清仓    │
         └──────────┘
```

## 6. 每日决策流程

### 6.1 开盘阶段（9:30）

```
1. 执行昨日挂单
   └── 如果有昨日挂的买单，以今日开盘价买入
   └── 买入后，记录买入价作为成本价

2. 检查开盘价是否触发卖出
   └── 不适用（金牛2保护策略在盘中阶段检查）
```

### 6.2 盘中阶段（9:30 - 15:00）

```
3. 计算天道指标（金牛、金牛2、BBI 等）
   └── 使用截至当日的全部历史数据

4. 检查盘中卖出信号
   └── 4a. 最高价 ≥ 金牛？ → 清仓止盈
   └── 4b. 最低价 ≤ 金牛2（全仓）？ → 减仓 50%
   └── 4c. 最低价 ≤ 金牛2 × 0.95（已减仓）？ → 清仓止损
```

### 6.3 收盘阶段（15:00）

```
5. 检查收盘卖出信号
   └── 5a. 收盘价 > 金牛2（已减仓）？ → 加仓买回 50%
   └── 5b. 持股天数 ≥ 35？ → 到期清仓

6. 更新持仓市值（按收盘价）

7. 策略选股（如果持仓有空位）
   └── 7a. 遍历股票池，计算 td_xg 信号
   └── 7b. 筛选出 td_xg == 1 的股票
   └── 7c. 按策略得分排序
   └── 7d. 挂买单（次日开盘执行）
```

| 手续费 | 0.1% | 买入和卖出各收一次 |

## 9. 完整示例

以下为一个完整交易周期的示例：

### 9.1 信号日（Day T）

```
股票：000001
日期：2024-03-15

当日K线：Open=9.80, High=9.85, Low=9.50, Close=9.75, Volume=15,000,000

天道指标：
  金钻趋势 = 10.00
  金牛 = 12.00
  金牛2 = 10.50
  BBI = 10.20

td_xg 信号判断：
  金钻趋势(10.00) > High(9.85)  ✓
  回调买(VAR23动量反转)         ✓
  → td_xg = 1（信号触发！）

操作：收盘后确认信号，挂买单
```

### 9.2 买入日（Day T+1）

```
日期：2024-03-16

开盘价：9.78
买入价：9.78 × (1 + 0.001) = 9.79（含滑点）

可用现金：100,000
分配资金：100,000 × 0.995 = 99,500
买入股数：floor(99,500 / 9.79 / 100) × 100 = 10,100 股

实际成交：买入 10,100 股 @ 9.79
成本价：9.79
持仓市值：98,879
```

### 9.3 持有期

```
Day T+2（2024-03-17）：
  天道指标：金牛=12.05, 金牛2=10.55
  最高价=9.90, 最低价=9.60
  检查：最高价 9.90 < 金牛 12.05，未触发止盈
        最低价 9.60 < 金牛2 10.55？ 否 → 不触发
  持仓不变

Day T+5（2024-03-20）：
  天道指标：金牛=12.10, 金牛2=10.58
  最高价=10.70, 最低价=10.30
  检查：最低价 10.30 < 金牛2 10.58？ 是！
  动作：减仓 50%，以金牛2价 10.58 卖出 5,000 股
  剩余：5,100 股

Day T+8（2024-03-23）：
  天道指标：金牛=12.15, 金牛2=10.60
  收盘价=10.65
  检查：收盘价 10.65 > 金牛2 10.60（已减仓状态）
  动作：加仓买回 50%，以收盘价 10.65 买入
  买回数量：按可用现金计算
  恢复全仓

Day T+15（2024-03-30）：
  天道指标：金牛=12.20, 金牛2=10.80
  最高价=12.30
  检查：最高价 12.30 ≥ 金牛 12.20
  动作：清仓止盈！以金牛价 12.20 卖出全部持仓
  盈利：(12.20 - 9.79) / 9.79 = 24.6%
```

## 10. 注意事项

### 10.1 信号计算时机

- **td_xg 信号必须在收盘后确认**，因为需要当日完整 K 线数据（High、Close 等）
- 不要在盘中根据未完成的 K 线做判断
- 实盘中，建议在 14:55 之后确认信号，次日开盘买入

### 10.2 数据要求

- 计算天道指标至少需要 120 个交易日的 K 线数据
- 使用前复权数据，避免除权除息导致信号失真
- 金牛2 是 EMA(金钻趋势, 25)，需要更长的历史数据才能稳定

### 10.3 回测与实盘差异

| 方面 | 回测 | 实盘建议 |
|------|------|----------|
| 成交价 | 按指定价格精确成交 | 使用限价单，避免滑点过大 |
| 跌停板 | 假设可以卖出 | 跌停板可能无法卖出，需人工判断 |
| 流动性 | 忽略 | 选择日成交额 > 5000万的股票 |
| 信号延迟 | 无 | 预留数据获取时间 |

### 10.4 风险提示

- 本策略基于历史数据回测，过去表现不代表未来收益
- 超跌反弹策略在熊市中可能连续止损
- 建议设置总资金回撤上限（如 20%），触及后暂停交易
- 金牛2 保护无法应对连续跌停的极端行情
